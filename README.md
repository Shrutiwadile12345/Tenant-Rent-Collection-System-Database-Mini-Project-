**TENANT RENT COLLECTION SYSTEM**

A SQL-based database project designed to manage rental properties, tenants, payments, and maintenance requests efficiently.

**OVERVIEW:**
This project helps property owners and tenants manage rent collection, property details, and maintenance records in a structured database system.
It demonstrates the use of SQL concepts such as DDL, DML, Joins, Subqueries, and PL/SQL components.

**FEATURES:**

* Manage Owners, Tenants, Properties, RentPayments, and MaintenanceRequests
* Track rent collection and payment history
* Perform DDL, DML, JOIN, and Subquery operations
* Use GROUP BY, HAVING, and Aggregate Functions for reports
* Includes PL/SQL components like Trigger, Function, and Procedure
* Normalized to Third Normal Form (3NF)

**TECHNOLOGIES USED:**

* MySQL
* ER Diagram
  
**HIGHLIGHTS:**

* Schema includes primary keys, foreign keys, constraints, and indexes
* Sample data with realistic rent and maintenance records
* Optimized queries for analytics and reporting
